# T-apk (Android client, Tater Plus + touch из Nullcki)

Клиент T-apk = форк Tater Plus (DDNet 17.4 + TaterClient) + бэкпорт touch-логики DDNet 20.2.1 из Nullcki (тач-кнопки, тач-меню). Версия клиента: 20.2.1.

- Сурс НЕ хранится в репо: workflow скачивает пин форка `dcaa51d597`,
  дополняет апстрим-деревом DDNet 17.4 и применяет бэкпорт touch-логики из
  Nullcki @59e02c55e7 (touch_controls.* и
  menus_ingame_touch_controls.* идентичны апстриму 20.2.1, проверено диффом).
- ddnet-libs материализуется из ddnet/ddnet-libs @c0e6703fbc (мастер с
  android-пребилдами arm64; пин gitlink-а 17.4 не содержит android/ каталогов).
- touch v2: раскладка кнопок (touch_controls.json) пакуется в APK;
  скролл списков в меню — жест ДВУХ ПАЛЬЦЕВ (клики при скролле не
  подаются, кнопки меню не нажимаются); кнопка "Paste" в правом
  верхнем углу вставляет текст из буфера обмена в активное поле
  (чат/консоль/меню).
- touch v5 (3.0.7): свайп от ЛЮБОГО края экрана (левого или правого)
  открывает игровое меню; повторный свайп закрывает его. Чат свайпом
  НЕ открывается — он открывается кнопкой "Chat" в доп-меню, а свайп
  при открытом чате ЗАКРЫВАЕТ его (в игру, без открытия меню);
  кнопка-"треугольник" из раскладки по умолчанию удалена (лонг-пресс
  кнопки доп-меню открывает меню, как и раньше); изменения раскладки
  тач-кнопок (редактор "Edit touch controls") СОХРАНЯЮТСЯ
  АВТОМАТИЧЕСКИ при закрытии меню/выключении редактора и больше не
  сбрасываются при перезаходе в игру.
- CI: ccache + кэши SDK/NDK/gradle/cargo — повторные сборки заметно
  быстрее первой (первая ~40 мин, дальше ~15-20 мин).
- APK: Releases -> tapk-v<N> -> T-apk.apk; подпись постоянная (CN=T-apk),
  обновления ставятся поверх старых без удаления и потери данных.
